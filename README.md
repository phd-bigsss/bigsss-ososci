## Workflow

1. **Run `proc/proc_prep-data.R`** — loads `car::Prestige`, recodes variables, saves `dfstudy1.RData` and codebook
2. **Run `proc/proc_main-analysis.R`** — produces descriptive tables, figures, and regression tables
3. **Render `main_document.qmd`** — fully reproducible HTML report combining all steps

```r
# From the project root in RStudio:
source(here::here("proc/proc_prep-data.R"))
source(here::here("proc/proc_main-analysis.R"))
```

```bash
# Render the report:
quarto render main_document.qmd
```

## Requirements

- R ≥ 4.3
- Quarto ≥ 1.5
- R packages: `pacman`, `here`, `car`, `dplyr`, `ggplot2`, `vtable`, `kableExtra`, `broom`, `texreg`, `sjPlot`, `scales`

Install all at once:

```r
if (!requireNamespace("pacman", quietly = TRUE))
  install.packages("pacman", repos = "https://cloud.r-project.org")

pacman::p_load(here, car, dplyr, ggplot2, vtable, kableExtra, broom, texreg, sjPlot, scales)
```

## Data

The example uses the **Prestige** dataset from the `car` package (Fox & Weisberg, 2018), covering 102 Canadian occupations with measures of prestige, income, education, and gender composition.
